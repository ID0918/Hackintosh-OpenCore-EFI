# Hackintosh-OpenCore-EFI
基于华硕EX-H410M-V3主板和英特尔Core i3 10100处理器以及AMD Radeon RX 5300独立显卡的OpenCore版配置文件

OpenCore核心和驱动全部使用最新构建版 1.0.9支持最新系统版本26.7.1【已验证】 伪装机型为iMac20,2

![Preview](/Files/Preview.png)

## 配置信息

| 硬件 | |
|-------------|-----------------------------------------------------|
| 主板 | 华硕 EX-H410M-V3 |
| 处理器 | 英特尔 Core i3 10100 |
| 显卡 | AMD Radeon RX 5300 |
| 网卡 | 瑞昱 RTL8168/8111 |
| 声卡 | 瑞昱 ALC887 |

台式配置无无线和蓝牙需要请自行添加修改
